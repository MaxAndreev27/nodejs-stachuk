# Security Policy

## Supported Versions

This project is a learning repository and is primarily maintained for educational purposes. Security updates are handled as issues arise, and the most recent version of the default branch is the main focus.

## Reporting a Vulnerability

If you discover a security vulnerability, please do not open a public issue.

Instead, report it privately through GitHub's Security Advisories for this repository:

- Open the repository on GitHub
- Go to the Security tab
- Choose "Report a vulnerability"

Please include:

- a clear description of the issue
- steps to reproduce it
- the impact and severity
- any suggested fix or mitigation

We will review the report and respond as quickly as possible.

## Response Expectations

We aim to acknowledge valid reports promptly and work toward a fix in a reasonable timeframe. Since this is an educational project, some issues may be addressed on a best-effort basis depending on scope and context.
