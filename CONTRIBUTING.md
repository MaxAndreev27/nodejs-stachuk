# Contributing

Thanks for your interest in contributing to this project.

This repository is a learning project for Node.js concepts, examples, and small exercises. Contributions are welcome if they improve clarity, fix issues, or add useful examples.

## How to Contribute

1. Fork the repository.
2. Create a feature branch from `main`.
3. Make your changes in a focused and clear way.
4. Keep code and examples easy to understand.
5. If you add new examples, describe what they demonstrate.
6. Open a pull request with a clear summary of the change.

## Code Style

- Use clear and readable JavaScript.
- Prefer simple and educational code over clever or overly abstract solutions.
- Add comments only when they help explain the concept.
- Keep examples consistent with the rest of the repository.

## Before You Submit

- Check that your code runs correctly with Node.js.
- If the change is related to a lesson or example, make sure it matches the topic of that folder.
- Keep the scope of your change narrow and easy to review.

## Reporting Issues

Before opening an issue, please check whether the topic already exists.

When reporting a bug or idea, include:

- a short description of the problem
- steps to reproduce it
- expected behavior
- actual behavior
- your environment (Node.js version, OS, etc.)

## Pull Requests

Please provide:

- a concise title
- a clear description of what changed
- any relevant screenshots or examples when helpful
- notes about verification if you tested the code

## Code of Conduct

Please read [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) before participating.
